# Privacy review

The repository uses generic account/repository examples. It contains no personal
usernames, home-directory paths, hostnames, controller serials, Wi-Fi details or
private network addresses from the earlier setup. Hardware and operating-system
names describe the public target platform, not an individual's equipment inventory.
The standard loopback address 127.0.0.1 is intentional functional configuration.

Before publishing future logs or screenshots, redact usernames, home paths, device
serials, tokens, Wi-Fi information and unrelated browser tabs. Do not commit browser
profiles, flight-controller backups or work/dist directories. The privacy review for
this artifact covers all shipped source and documentation, not future build output
or logs generated on a different machine. See VALIDATION.md for the performed checks.
